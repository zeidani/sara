# Sarah A. Zeidani — Professional Feminine Profile

Professional responsive profile website for Sarah A. Zeidani.

## Current refinements
- Free-floating transparent portrait instead of a framed image.
- Stronger dark-theme text contrast with a refined feminine palette.
- Arabic display name: سارة أ. زيداني.
- English is the default language on first visit.
- Five-language selector: English, Arabic, Italian, Chinese, Hindi.
- Reliable animated counters with IntersectionObserver fallback.
- Responsive layout for desktop, tablet and mobile.
- Floating hearts/flowers remain part of the visual identity.
